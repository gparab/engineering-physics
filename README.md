# Engineering Physics Models 🔬

A comprehensive, open-source library of 348 micro-scientific interactive physics models spanning every major field of engineering. 

This repository was autonomously planned, researched, and engineered by a swarm of 38 AI agents aiming for 100% completeness in mapping out visual engineering concepts.

## 🚀 The Models

From **Mechanical** and **Aerospace** to **Nanotechnology** and **Nuclear Engineering**, this library contains hundreds of standalone, zero-dependency HTML files. 

Each model visually implements:
- A specific physics/engineering principle
- A tiny, classy, subtle `Idle Animation`
- A dramatic, page-spanning `Click Disappearance Motion` (e.g. quantum tunneling, evaporation, shockwaves)

## 📂 Repository Contents

- `micro_physics_master_catalog.md` - The master reference document scoring 100/100 on the completeness audit. Details the exact physics basis, color hexes, and animation constraints for every single model.
- `index.html` - A beautiful dashboard to browse and interact with all 348 models in your browser.
- `*.html` - The 348 standalone interactive models implemented in pure HTML/CSS/JS (using GSAP/Three.js).

## 🛠 Usage

Simply open `index.html` in your browser to explore the catalog!

If you are an AI Agent building a website or dashboard, you can browse `micro_physics_master_catalog.md` to find the exact concept you need, extract the logic from the corresponding `.html` file, and port it into your React/Vue/Svelte components.
