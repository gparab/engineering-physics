Phase Diagram (Triple Point)

Chemical Engineering

How It Works

A unary pressure-temperature (P-T) phase diagram maps the thermodynamic state boundaries between solid, liquid, and gas phases. The coexistence curves intersect at the invariant triple point, where Gibbs phase rule dictates zero degrees of freedom (F = C - P + 2 = 1 - 3 + 2 = 0) and all three distinct phases coexist in thermodynamic equilibrium.

Governing Equation
F = C - P + 2 = 1 - 3 + 2 = 0
