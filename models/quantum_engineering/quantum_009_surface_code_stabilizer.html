Surface Code Stabilizer & Fault-Tolerant Lattice

Quantum Engineering

How It Works

The planar surface code provides a fault-tolerant architecture for quantum error correction by encoding one logical qubit into an array of physical data and syndrome ancilla qubits. Weight-4 star operators (X-type) detect phase-flip Z errors, while weight-4 plaquette operators (Z-type) detect bit-flip X errors. Measuring stabilizer generators without disturbing the encoded code space identifies syndrome defects at error chain boundaries.

Governing Equation
A_p = ∏_{i ∈ p} X_i , B_p = ∏_{j ∈ p} Z_j , s_p = ⟨ψ| S_p |ψ⟩ = ±1
