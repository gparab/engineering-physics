Phased Array

Telecommunications

How It Works

A phased array antenna consists of multiple stationary radiating elements where the relative phase shift of the excitation signal feeding each element is electronically varied. Through spatial constructive and destructive interference, the individual electromagnetic wavefronts combine into a highly focused, directional main beam. By continuously updating the progressive phase delay Δφ, the antenna beam is steered instantaneously across space without physical mechanical inertia.

Governing Equation
AF(ψ) = ∑_{n=0}^{N-1} e^{j n ψ} = sin(N ψ / 2) / sin(ψ / 2)   |   ψ = k · d · sin θ + β   |   θ_{steer} = arcsin(-β / kd)
