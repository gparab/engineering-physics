Bloom Filter

Computer Science

How It Works

A Bloom filter is a compact, space-efficient probabilistic data structure applied to verify set membership with zero false negative determinations and bounded false positive probabilities. The structure comprises an m-bit array initialized to zero. Inserting an element entails evaluating k independent hash functions that set the corresponding array bit positions to 1; query lookups confirm membership only if all k hashed indices are set.

Governing Equation
$$ p_{\text{fp}} \approx (1 - e^{-k n / m})^k \quad\vert\quad k_{\text{opt}} = \frac{m}{n} \ln 2 $$
